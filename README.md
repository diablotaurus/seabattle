# Морской бой

Классический морской бой 10×10 против компьютера: три уровня сложности, расстановка перетаскиванием, звуки, журнал боя, статистика и сохранение незаконченной партии. Работает на компьютере и на телефоне.

**Играть:** https://diablotaurus.github.io/seabattle/ — обновляется автоматически после каждого push в `main` (GitHub Actions → `.github/workflows/pages.yml`).

## Как запустить

Просто открыть `index.html` в браузере — вся игра в одном файле, без сервера и установки.

## Правила

Флот: линкор (4), два крейсера (3), три эсминца (2), четыре катера (1). Корабли не касаются друг друга даже углами. Попал — стреляешь ещё раз.

## Уровни сложности

| Уровень | Как играет | Выстрелов, чтобы потопить флот (в среднем) |
|---|---|---|
| Юнга | стреляет наугад, иногда бросает раненый корабль | ~89 |
| Капитан | всегда добивает раненые корабли | ~69 |
| Адмирал | карта вероятностей по всем возможным расстановкам | ~55 |

## Структура

```
index.html    игра целиком: разметка, стили, логика
prototypes/   исходные прототипы v0.0.1–v0.0.2
```

Статистика и сохранённая партия хранятся в `localStorage` браузера — на каждом устройстве свои.
